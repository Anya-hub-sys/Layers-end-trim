Sequential Trim Selected Layers – After Effects JSX

A simple Adobe After Effects script that trims selected layers' end points sequentially using custom frame intervals.

How to Use

1. Select multiple layers in your After Effects timeline.
2. Position the playhead at the desired trim point.
3. Run the ".jsx" script via File → Scripts → Run Script File.
4. Enter a frame interval (e.g., "5") or a repeating pattern (e.g., "5,3,5").
5. The script trims layer end points progressively backward from the playhead.

Features

- Supports custom and repeating frame intervals.
- Modifies only layer end points ("outPoint").
- Preserves original layer positions and start times.
- Processes layers according to timeline order.

Compatibility: Adobe After Effects (JSX / ExtendScript).
